## 四、相邻类型对决

### 对决 1：INTJ vs ENTJ（最关键）

**共同表象**：Ni-Te、长线战略、高标准、独立、不接受模糊授权（E07/E08）。

| 区分点 | 倾向 INTJ 的回答 | 倾向 ENTJ 的回答 | 当前材料（2026-09-03 更新） |
| --- | --- | --- | --- |
| 无义务的空闲时间，思维默认**打磨私人模型**还是**优化外部项目**？ | 私人模型 | 外部项目 | ✅ **打磨私人模型**（E27）→ INTJ |
| 持续调度多人，是让你更兴奋锋利，还是**虽能胜任但明显耗能**？ | 耗能 | 兴奋 | ✅ **想撤退**（E28）→ INTJ |
| 新构想在**对话中形成并推进**，还是**先在内部成形、对话只用于测试和落地**？ | 内部成形 | 对话中成形 | ✅ **图书馆独处时成形**（E29）→ INTJ |
| 重压下更容易出现价值羞耻／脆弱爆发，还是感官过载／冲动失衡？ | 价值羞耻/脆弱 | 感官过载/冲动 | 偏 **INTJ**（E15/E21/E25 都是 Fi + Se 劣势双爆发） |

**判决（2026-09-03）**：4 问全部指向 INTJ，ENTJ 降为**低可能候选**。

### ⚠️ 但必须打折：E27–E29 高度相关，不是三个独立证据

三条新证据有一个**共同原因**——「当前偏好独处、且独处条件充足」。证据账本的规则是
「不重复测同一倾向」，而 E10（独处恢复）已经在测同一条主线。因此：

- 三条的**实际独立信息量约等于 1–1.5 条**，置信度提升幅度必须小于表面看起来；
- 三条共享同一个竞争解释：**人生阶段**。现在是本科进组前、身边缺少同水平对话者、也没有
  可自由调度的团队——「没有外部项目可推」和「不想推外部项目」在这三条里**无法区分**；
- 方法文档明确要求：「只来自工作、恋爱或公开社交账号的单一角色」需要降权——目前语料
  高度集中在**学生／自学／个人项目**这一个角色上。

**所以对 ENTJ 的排除是"阶段性排除"而非"永久排除"**：进组带团队、或开始推一个真正需要
调度多人的项目之后，必须重测这三条。

### 对决 2：INTJ vs INFJ

**共同表象**：Ni 主导、私人、模式化、远期关注（E01/E02）。

- E13（读不出话外音、忍到憋屈）**强烈反对 Fe 辅助**；
- E03（给家人大头）表面像 Fe，但更像是 **Fi 的内在价值排序**——他给的是"我认为该给的人"，不是"维持关系场和谐"；
- E14（两个 INFJ 好友很懂他）是互补吸引，不是同型识别。

**判决**：INFJ 降为**低可能候选**，保留到拿到"关系场破裂 vs 背叛内在立场"这一问的回答为止。

### 对决 3：INTJ vs INTP

E06（计划被打乱很烦躁、"没完成就不可能完全放松"）+ E24（要"确认万无一失再执行"）**强烈反对 P 主导**。
INTP 的 Ti-Ne 会停在"还有个更好的可能"，他的行为是"定了就推到底"。

**判决**：**排除**。

### 对决 4：INTJ vs ISTJ

两者都 J、都闭环。区分在 Ni 未来模型 vs Si 历史连续性：
- E01 规划的是**尚未存在的路径**（AI + 叶轮机械的新交叉）；
- E22 打脸链路是**向前预测再修正**，不是"照过去的验证方法做"；
- E26（论文还没读完就把目标定到一区一作）是典型的**目标先于经验**。

**判决**：ISTJ 降为**低可能候选**；保留一条反证——若他的工程判断主要来自"过去案例和已验证方法"，则回摆 ISTJ。

## 五、Big Five 交叉校验（〔推断〕，仅作竞争解释）

| 维度 | 估计 | 依据 | 为什么重要 |
| --- | --- | --- | --- |
| 开放性 O | 高 | 自建 AI 平台、蒸馏自己、跨领域迁移（E22/E23） | 高 O 会放大 N 的表象 |
| 尽责性 C | **很高** | 作息锚点、计划性、过度交付、未完成不放松（E06） | ⚠️ **高 C 会独立制造"J"表象**——E06 的强度可能被 C 污染，不能单独用来判 J/P |
| 外向性 E | 低–中 | E10/E11/E12 | 与 I 一致，但非极端 |
| 宜人性 A | 低–中 | E05 杀伐果断、E08 零容忍无能上司、E09 记在案 | 低 A 常被误读为"T 更强"，需与 Te 区分 |
| 神经质 N | 中 | 自我怀疑、完美主义、低自信答对、情绪冲动（E15/E25） | ⚠️ **这是"情绪化 INTJ"最可能的非 MBTI 解释** |

**关键提醒**：E06（J 表象）与 E15/E25（情绪化）都可能由 Big Five 的 C 与 N 解释，而不必全塞进 MBTI 四维。**这也是本账本不给百分比的原因。**

## 六、工作结论（可推翻）

> **领先类型：INTJ（置信度：中高 → 高，2026-09-03 上调）**
> **备选：ENTJ（低，阶段性排除）> INFJ ≈ ISTJ（低）；INTP 已排除。**

支持结论的最硬证据：
1. **E10 + E27/E28/E29**（I 与 Ni 内部主线，四个不同问法互证）；
2. **E13**（非 Fe 辅助，判定书 + 恋爱实例 + 自述三源互证）；
3. **E01/E22**（Ni-Te 的向前预测闭环）。

**上调理由**：INTJ vs ENTJ 的 4 个高区分问题（对决 1）全部落定，且全部指向 INTJ。
**不上调到"很高"的理由**：E27–E29 共享「当前偏好独处」这一共因，独立信息量打折；
且语料高度集中于「学生／自学」单一角色，缺少**带团队、进组之后**的反向检验场景。

对"情绪化 INTJ"的解释（〔推断〕）：不是类型的矛盾，而是**三项叠加**——
① Fi 在第三位，被触及时反应激烈但缺乏表达通道（E13/E21）；
② Se 劣势，高压下抓握反扑（E15/E16/E25）；
③ Big Five 神经质中等，拉高了情绪波动的基线。
三者都不是"他其实是 F 型"的证据。

### 推翻条件（出现即重判）

| 现象 | 改判方向 |
| --- | --- |
| **进组／带团队之后**，发现调度多人反而是能量来源，空闲时想的是外部项目 | → **ENTJ**（这是最现实的一条回摆路径，E27–E29 的阶段性偏差会在此暴露） |
| 关系场破裂本身就是他的第一痛点（而非"事情推不动"） | → **INFJ** |
| 工程判断主要来自历史案例与已验证方法，而非未来模型 | → **ISTJ** |
| 定了的计划可以因为"出现更好的可能"而整体推翻重来，且不烦躁 | → **INTP**（重新入局） |
| 上述现象混合出现，且随场景波动很大 | → 放弃单一类型结论，改用 Big Five + 场景化描述 |

## 七、明确不做（照抄方法文档红线）

- 不给功能百分比、匹配率、"你 73% 是 INTJ"式的假精确数字；
- 不从单一场景、单一角色（尤其只用 GitHub 仓库行为）下定论；
- 不把"INTJ 必然冷静/聪明/孤独"这类刻板印象反向套回他身上；
- 不用此结论做任何招聘、升学、关系淘汰的依据；
- 不把 A/T 当官方第五维；不混用依恋类型与 MBTI。
