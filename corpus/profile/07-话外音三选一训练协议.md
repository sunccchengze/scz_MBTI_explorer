# 07 · 话外音「三选一」训练协议

> **用途**：立项问题②——把「读不懂人」变成可训练动作，而不是人格标签。
> **挂载**：可同步到 `zixue2026` 的 drill-ledger（本仓只定义协议；他仓是否建账由本人决定）。
> **建立**：2026-09-03 · 本人授权六件事全做。

## 一、结论先行

不训练「读心」，只训练**出口**：

听到一句可能有话外音的话 → 30 秒内写出 **A 字面 / B 情绪 / C 请求** → 选一个去问 → 记下对错。

目标不是命中率 100%，是把「我读不懂所以不说」（E13）改成「我读不懂所以给出三个选项让对方选」。

## 二、标准动作（一次 ≤ 2 分钟）

1. **原话照抄**（不许改写、不许补潜台词）。
2. 强制写三个互斥翻译：
   - A 字面：她/他就是字面意思；
   - B 情绪：主要在表达感受（委屈/累/试探），内容是载体；
   - C 请求：主要在要一个具体动作（陪、回、改、停）。
3. **只问一个**：把三个压缩成一句可发送的话，例如：
   > 「我听成了三种：①就是字面；②你其实有点〔情绪〕；③你希望我〔动作〕。你是哪一种？我按你选的做。」
4. **记一笔**（见下方账本模板）：猜的是 A/B/C，对方选的是哪条，延迟分钟数。

禁止项：一次发三句解释；用「你是不是在……」连环审讯；猜完不发、只在脑子里演（那是延迟暴露复发）。

## 三、drill-ledger 模板（本仓副本）

账本已建：`corpus/memory/drill-话外音.md`（2026-09-03 第一笔 = 酒馆原话复盘，非当场发出）。

计分（给自己看，不对外）：

- **出口率** = 发出三选一的次数 / 意识到「可能有话外音」的次数；
- **误差发现延迟** = 从听到到发出的分钟数（越小越好；发错也算发出）；
- **命中率**暂不作为主指标（样本小时会骗人）。

## 四、和监护协议的接口

- 命中 **#2 评价回避** 或 **#9 延迟暴露**：当场把「拿不准就不说」改成「发三选一」。
- 命中 **#5 情绪冲动**：三选一写完先放 24 小时再发（恋爱承诺类）；日常澄清类当场发。

## 五、验收（本人可改）

连续 10 次「意识到话外音」里，出口率 ≥ 7/10，本协议从「未开练」升为「在练」。未达线不改人格结论，只说明训练没开始。
