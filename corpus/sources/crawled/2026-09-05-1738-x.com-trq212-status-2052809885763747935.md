## 正文要点（按原文顺序）

1. "This is now also on the Claude Blog." —— 已同步到 Claude 官方博客。
2. Markdown 已成为 agent 与人沟通的主导格式：简单、可移植、易编辑；Claude 甚至擅长用 ASCII 画 Markdown 里的图。
3. 但 agent 越来越强之后，Markdown 变成**限制格式**："I find it difficult to read a markdown file of more than a hundred lines." 想要更丰富的可视化、颜色、图，且要容易分享。
4. 而且越来越多时候**不是自己编辑这些文件**，而是当 spec / 参考 / 头脑风暴产物用；真要改也是让 Claude 改——这消掉了 Markdown 最大优势（人好编辑）。
5. "I've started preferring HTML as an output format instead of Markdown"，Claude Code 团队其他人也在这么用。

### Why HTML?
- **Information Density（信息密度）**：表（table）、设计（CSS）、插图（SVG）、代码（script）、交互（HTML+JS+CSS）、工作流（SVG+HTML）、空间数据（绝对定位/canvas）、图片。"几乎没有 Claude 读得的信息集不能用 HTML 高效表示。" 反例：模型在 Markdown 里做低效事，如 ASCII 图、用 unicode 字符估色。
- **Visual Clarity & Ease of Reading**：HTML 文档更易读，可用 tabs/插图/链接组织、可移动响应式。
- **Ease of Sharing**：Markdown 要当附件发；HTML 传个链接（如 S3）即可，"同事真正读你的 spec 的概率高得多"。
- **Two-way Interaction（双向交互）**：文档里放 sliders/knobs 调参数，把改动 copy 回 prompt 粘回 Claude Code（另见其 playgrounds 帖 x.com/trq212/status/2017024445244924382）。
- **Data Ingestion（数据摄入）**：用 Claude Code 做 HTML 的理由之一是它能吞的上下文（文件系统/MCP/浏览器/git 历史）。写这篇长文时，他让 Claude Code 读他生成的全部 HTML 文件、分类、为每类画图——长文里的图就是这么来的。
- **It's Joyful**：做 HTML 文档更 fun，更投入。

### How to Get Started
- 不需要建 /html skill："You can just ask it to 'make a HTML file' or 'make a HTML artifact'."
- 关键 trick：**想清楚 artifact 要干什么、你会怎么用**。熟练了再考虑沉淀成 skill。

### Use Cases（正文给出 + 官方示例站全量 9 类 20 例，2026-09-05 抓取自 thariqs.github.io/html-effectiveness）
1. **Exploration & Planning**（3）：代码方案并排对比（grid+tradeoff 标注）/ 视觉设计方向（live 渲染）/ 实现计划（时间线里程碑+数据流图+mockup+风险表）
2. **Code Review & Understanding**（3）：带边注的 diff（severity 着色+跳转）/ 给 reviewer 的 PR 说明 / 模块图（盒子+箭头，热路径高亮）
3. **Design**（2）：活的 design system（tokens→色板可抄）/ 组件变体 contact sheet
4. **Prototyping**（2）：动画沙盒（duration/easing 滑杆）/ 可点击流程（4 屏串联）
5. **Illustrations & Diagrams**（2）：SVG 插图页 / 可点击流程图（点步骤看内容/耗时/失败路径）
6. **Decks**（1）：方向键翻页的 slide deck（一个 HTML 文件，无构建步骤）
7. **Research & Learning**（2）：功能讲解（TL;DR 框+可折叠步骤+tab 代码+FAQ）/ 概念讲解（可交互哈希环+对照表+悬停术语表）
8. **Reports**（2）：周报（上了什么/掉了什么+小图表）/ 事故时间线（逐分钟+日志摘录+跟进清单）
9. **Custom Editing Interfaces**（3）：拖拽分诊板（导出 markdown）/ feature flag 编辑器（依赖警告+copy diff）/ prompt 调参器（模板+3 个样例实时重渲染）——**共同点：永远以导出按钮收尾，把 UI 操作结果变回可粘回 agent 的东西**
