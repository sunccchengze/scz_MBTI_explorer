`documentation/mbti-skill-research.md` 显示，这 12% 是认真做的：

- 调研了 10 个 GitHub MBTI skill，按「方法质量 / 科学边界 / 实用性 / 安全隐私 / 工程质量 / 许可证」六项打分；

方法骨架是对的。问题是：**它挂在一个恋爱军师身上，而且没有「用户本人」这个主语。**

## 四、缺的那块：语料

| 需要 | 状态 | 说明 |
